# Temperature Conversion Formulas

This document contains the mathematical formulas used in the Temperature Converter project.

## 1. Celsius to Fahrenheit

Formula:

`F = (C × 9/5) + 32`

## 2. Fahrenheit to Celsius

Formula:

`C = (F - 32) × 5/9`

## 3. Celsius to Kelvin

Formula:

`K = C + 273.15`

## 4. Kelvin to Celsius

Formula:

`C = K - 273.15`

## 5. Fahrenheit to Kelvin

Formula:

`K = ((F - 32) × 5/9) + 273.15`

## 6. Kelvin to Fahrenheit

Formula:

`F = ((K - 273.15) × 9/5) + 32`

## Important Note

- Absolute zero is 0 K, -273.15 °C or -459.67 °F.
