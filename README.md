# Temperature Converter

A Python project that converts temperatures between Celsius, Fahrenheit, and Kelvin.

## Features

- Converts between all three temperature units.
- Supports six conversion options.
- Validates temperature inputs.
- Prevents temperatures below absolute zero.
- Handles invalid user inputs.
- Allows users to perform multiple conversions.

## Technologies Used

- Python 3
- Python built-in functions and modules

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python main.py
```

## Conversion Formulas

- Celsius to Fahrenheit: `(C × 9/5) + 32`
- Fahrenheit to Celsius: `(F - 32) × 5/9`
- Celsius to Kelvin: `C + 273.15`
- Kelvin to Celsius: `K - 273.15`
- Fahrenheit to Kelvin: `(F - 32) × 5/9 + 273.15`
- Kelvin to Fahrenheit: `(K - 273.15) × 9/5 + 32`
